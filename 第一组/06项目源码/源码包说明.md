# 项目源码说明

源码包：校园助手项目源码.zip

包含内容：

- CampusAssistant：HarmonyOS ArkTS 移动端源码。
- Campus-Server：Spring Boot 后端源码。
- web-admin：Vue 管理后台源码。
- campusdb2.sql：MySQL 初始化脚本。
- 01-database.md、02-api-doc.md、03-structure.md、04-api-template.md：数据库、接口和结构说明。

未打包内容：.git、target、dist、node_modules、oh_modules、build 等构建产物或依赖目录。
