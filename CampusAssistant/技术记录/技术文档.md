# 技术文档

## 2026-07-20 首页重构 + 底部Tab改造

实现了首页按 preview-ui.html 原型重构，包括 Banner 卡片、快捷入口网格、失物招领大卡片、今日课表+我的报名并排布局、校园公告列表，通过 ArkUI Tabs + linearGradient + Flex 布局技术实现。课表从底部Tab移至首页快捷入口，新增独立 SchedulePage 子页面，通过 router.pushUrl 跳转。底部Tab改为首页/二手/消息/AI/我的 五栏布局，新增消息Tab的 ChatListContent 对话列表。

遇到了编辑替换后多余闭合大括号导致编译报错的问题，用 awk 检查大括号平衡性后定位并修复方法解决。

## 2026-07-20 快捷入口布局调整

实现了快捷入口2x2网格+失物招领等宽并排布局，课表/空教室/社团互动/AI助手左半区2行2列，失物招领右半区等宽渐变卡片，通过 Row + Column layoutWeight(1) 双栏均分布局技术实现。

## 2026-07-22 修复消息Tab跳转空白页Bug

实现了消息Tab点击直接跳转ConversationListPage且返回不回到空白页，通过在Tabs.onChange中拦截index=2阻止tab切换并直接pushUrl跳转，同时在onPageShow中检测currentTab为2时重置回previousTab技术实现。

遇到了点击消息tab先显示空白MessageContent再跳转导致体验不丝滑、以及从ConversationListPage返回后currentTab仍为2显示空白页的问题，用记录previousTab并在onChange拦截+onPageShow重置方法解决。遇到了仅修改currentTab无法阻止Tabs视觉切换导致底部tab栏消失的问题，用TabsController.changeIndex强制切回previousTab方法解决。

## 2026-07-23 消息Tab内嵌会话列表

实现了消息Tab直接内嵌会话列表，点击底部tab即可查看会话无需页面跳转，通过将ConversationListPage的会话加载、WebSocket消息处理、在线状态管理逻辑整合到MainPage的MessageContent Builder中技术实现。移除了之前的onChange拦截+pushUrl跳转方案，改为正常切换tab时懒加载会话数据。

## 2026-07-23 全局导航栏统一为NavHeader

实现了13个页面的自定义导航栏统一替换为NavHeader组件，通过NavHeader的title属性和@BuilderParam rightSlot技术实现，右侧操作按钮（发布/刷新/清空/保存/删除等）放入rightSlot。ChatPage的在线状态和商品号信息从导航栏移至NavHeader下方独立Row展示。

## 2026-07-23 头像显示Bug修复

实现了编辑资料页头像即时更新和其他页面头像同步，通过将AvatarView的avatar和name改为@Prop使其响应式更新、onPageShow中创建新UserInfo对象触发@State变化检测技术实现。修复了AvatarView图片URL判断仅支持/开头的逻辑，增加http/https前缀支持。更换了编辑资料页emoji列表为更适合做头像的动物和自然类emoji。

遇到了@State赋值同一对象引用不会触发UI刷新的问题，用创建新对象浅拷贝方法解决。
