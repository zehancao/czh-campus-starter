## 二、后端命名规则

### 2.1 包结构（严格遵守现有结构）

```
com.campus
├── entity/       ← 实体类，与表名对应
├── mapper/       ← MyBatis-Plus Mapper 接口
├── service/      ← Service 类
├── controller/   ← Controller 类
├── dto/          ← VO/DTO 返回给前端的数据对象
└── common/       ← Result 等公共类
```

### 2.2 类命名

| 层 | 命名格式 | 示例 |
|---|---------|------|
| Entity | PascalCase，与表名单数对应 | `CarpoolOrder` → 表 `carpool_orders` |
| Mapper | `{Entity}Mapper` | `CarpoolOrderMapper` |
| Service | `{Entity}Service` | `CarpoolOrderService` |
| Controller | `{模块}Controller` | `CarpoolController` |
| VO | `{Entity}VO` | `CarpoolOrderVO` |

### 2.3 表命名

- 小写蛇形：`carpool_orders`、`study_shares`
- 关联表：`study_together_joins`
- 表名与 Entity 的 `@TableName` 必须一致

### 2.4 Entity 字段规范

- `id`：`Long`，`@TableId(type = IdType.AUTO)`
- 时间字段：`LocalDateTime`，数据库对应 `DATETIME`
- 状态字段：`Integer`，在文档中说明每个值的含义
- 外键字段：`{关联}Id`，如 `userId`、`activityId`
- 必须写 getter/setter（不要用 Lombok，项目未引入）

## 三、API 规范

### 3.1 URL 格式

```
/api/{模块名}/{动作}
```

- 模块名用短横线：`/api/club-activity/list`、`/api/carpool/list`
- 动作词：`list`、`detail`、`publish`、`delete`、`join`、`cancel` 等

### 3.2 请求方式

| 操作 | 方法 | 示例 |
|------|------|------|
| 查列表 | GET | `GET /api/carpool/list?status=1` |
| 查详情 | GET | `GET /api/carpool/detail?id=1` |
| 创建 | POST | `POST /api/carpool/publish` Body: JSON |
| 操作类（加入/取消/举报） | POST | `POST /api/carpool/join?id=1` |
| 上传文件 | POST | `POST /api/study-share/upload` multipart/form-data |

### 3.3 认证

- 所有需登录的接口通过 `@RequestAttribute("userId") Long userId` 获取当前用户
- 拦截器自动注入，无需前端传 userId
- 公开接口加 `required = false`

### 3.4 返回格式

```json
{
  "code": 200,
  "msg": "success",
  "data": ...
}
```

- 成功：`Result.ok(data)`
- 失败：`Result.error(400, "报名失败")`

### 3.5 分页（如需要）

- 参数：`?page=1&size=20`（默认 page=1, size=20）
- 返回 data 为数组，暂不做总数

## 四、前端命名规则

### 4.1 文件命名

| 类型 | 格式 | 示例 |
|------|------|------|
| 页面 | PascalCase + Page | `CarpoolPage.ets`、`CarpoolDetailPage.ets` |
| 发布页 | PascalCase + PublishPage | `CarpoolPublishPage.ets` |
| Model | Models.ets（统一追加） | 在 `entry/src/main/ets/model/Models.ets` 中添加新 class |
| Service | ApiService.ets（统一追加） | 在 `entry/src/main/ets/service/ApiService.ets` 中添加新方法 |

### 4.2 Model class 命名

```typescript
export class CarpoolOrder {
  id: number = 0;
  userId: number = 0;
  departure: string = '';
  destination: string = '';
  departureTime: string = '';
  maxPassengers: number = 0;
  currentPassengers: number = 0;
  status: number = 0;       // 0=招募中 1=已满 2=已出发 3=已取消
  remark: string = '';
  createTime: string = '';
  publisherName: string = '';
}
```

- 字段名用 camelCase
- 必须给默认值（ArkTS 要求）
- 新 Model 统一追加到 `Models.ets`，**不要新建文件**

### 4.3 ApiService 方法命名

```typescript
static async getCarpoolList(status: number): Promise<ApiResult> { ... }
static async getCarpoolDetail(id: number): Promise<ApiResult> { ... }
static async publishCarpool(params: Record<string, Object>): Promise<ApiResult> { ... }
static async joinCarpool(carpoolId: number): Promise<ApiResult> { ... }
```

- 方法名：`{动词}{模块名}`
- GET 参数放 URL query
- POST 参数放 Body（JSON）

### 4.4 页面注册

新页面必须在 `entry/src/main/resources/base/profile/main_pages.json` 中注册，否则无法跳转。

### 4.5 页面跳转传参

```typescript
// 跳转详情页
this.getUIContext().getRouter().pushUrl({
  url: 'pages/CarpoolDetailPage',
  params: { 'id': `${orderId}` } as Record<string, string>
});

// 详情页接收
aboutToAppear() {
  const params = this.getUIContext().getRouter().getParams() as Record<string, string>;
  if (params !== undefined) {
    this.orderId = Number(params['id']) ?? 0;
  }
}
```

- 参数全部用 string 传递，接收时转 Number
- 不要用 `router.getParams()`（已废弃），用 `this.getUIContext().getRouter().getParams()`

### 4.6 UI 规范

- 主题色统一使用 `Theme` 类：`Theme.primary`（暖橙）、`Theme.ocean`（海洋蓝）
- 背景色：`Theme.bgPage`、`Theme.bgCard`
- 文字色：`Theme.textPrimary`、`Theme.textSecondary`、`Theme.textTertiary`
- 圆角：`Theme.cardRadius`（16）、`Theme.radiusSm`（8）
- 阴影：`ShadowStyle.sm`、`ShadowStyle.md`
- 导航栏复用 `NavHeader` 组件：`NavHeader({ title: '拼车回家' })`
- 不要硬编码颜色值
