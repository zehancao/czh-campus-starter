# 功能四：校园安全一键报（CampusSafety）

> 紧急情况一键求助，查看校园安全信息

---

## 一、功能描述

1. 用户一键发送求助信号（选择紧急类型+位置描述+可选图片）
2. 查看求助记录列表
3. 管理员（或所有用户）可查看待处理求助
4. 用户可以标记求助为"已解决"
5. 校园安全公告/通知展示
6. 紧急联系电话一键拨打（前端本地功能）

---

## 二、数据库建表

### 2.1 safety_reports（求助报告表）

```sql
CREATE TABLE safety_reports (
  id BIGINT AUTO_INCREMENT PRIMARY KEY,
  user_id BIGINT NOT NULL COMMENT '报告人ID',
  type VARCHAR(20) NOT NULL COMMENT '紧急类型：人身安全/财物丢失/火情/医疗/其他',
  location VARCHAR(200) DEFAULT '' COMMENT '位置描述',
  description VARCHAR(1000) DEFAULT '' COMMENT '情况描述',
  images VARCHAR(1000) DEFAULT '[]' COMMENT '图片路径JSON数组',
  status INT DEFAULT 0 COMMENT '0=待处理 1=处理中 2=已解决 3=误报',
  handler_id BIGINT DEFAULT NULL COMMENT '处理人ID',
  handle_remark VARCHAR(500) DEFAULT '' COMMENT '处理备注',
  create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
  handle_time DATETIME DEFAULT NULL COMMENT '处理时间',
  INDEX idx_user_id (user_id),
  INDEX idx_status (status),
  INDEX idx_create_time (create_time)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='安全求助报告';
```

### 2.2 safety_contacts（紧急联系电话表）

```sql
CREATE TABLE safety_contacts (
  id BIGINT AUTO_INCREMENT PRIMARY KEY,
  name VARCHAR(50) NOT NULL COMMENT '名称',
  phone VARCHAR(20) NOT NULL COMMENT '电话号码',
  category VARCHAR(20) DEFAULT '其他' COMMENT '分类：安保/医疗/消防/心理/其他',
  sort_order INT DEFAULT 0 COMMENT '排序',
  is_active INT DEFAULT 1 COMMENT '1=启用 0=停用'
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='紧急联系电话';
```

## 五、关键业务逻辑

1. **一键求助**：首页入口点击后直接跳到提交页，大按钮快速提交，减少操作步骤
2. **紧急类型**：`人身安全`/`财物丢失`/`火情`/`医疗`/`其他`，前端用横向选择器
3. **紧急电话**：前端展示为卡片列表，点击调用系统拨号（`call` 权限需在 module.json5 声明）
4. **处理状态流**：待处理(0) → 处理中(1) → 已解决(2)；误报直接标3
5. **处理人**：目前所有用户都可处理（后续可限制为管理员）

## 六、权限声明

在 `module.json5` 的 `requestPermissions` 中添加拨打电话权限（如果需要一键拨打功能）：

```json
{
  "name": "ohos.permission.MAKE_CALL",
  "reason": "$string:call_reason",
  "usedScene": {
    "abilities": ["EntryAbility"],
    "when": "inuse"
  }
}
```

并在 `resources/base/element/string.json` 中添加：
```json
{ "name": "call_reason", "value": "用于紧急情况下一键拨打求助电话" }
```
