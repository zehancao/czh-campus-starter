# 功能五：学习资料共享（StudyShare）

> 分享课程资料，互帮互助，上传/下载/收藏学习资源

---

## 一、功能描述

1. 用户上传学习资料（支持PDF/图片/文档，选择关联课程）
2. 浏览资料列表，按课程/分类筛选
3. 查看资料详情，下载资料
4. 点赞资料
5. 收藏资料
6. 举报违规资料
7. 查看我上传的和我收藏的资料

---

## 二、数据库建表

### 2.1 study_shares（学习资料表）

```sql
CREATE TABLE study_shares (
  id BIGINT AUTO_INCREMENT PRIMARY KEY,
  user_id BIGINT NOT NULL COMMENT '上传者ID',
  title VARCHAR(200) NOT NULL COMMENT '资料标题',
  description VARCHAR(500) DEFAULT '' COMMENT '资料描述',
  course_name VARCHAR(100) DEFAULT '' COMMENT '关联课程名',
  category VARCHAR(20) DEFAULT '其他' COMMENT '分类：课件/笔记/真题/作业/其他',
  file_url VARCHAR(500) NOT NULL COMMENT '文件路径',
  file_type VARCHAR(20) DEFAULT '' COMMENT '文件类型：pdf/jpg/png/doc/ppt/xls等',
  file_size BIGINT DEFAULT 0 COMMENT '文件大小(字节)',
  cover_image VARCHAR(500) DEFAULT '' COMMENT '封面图路径',
  like_count INT DEFAULT 0 COMMENT '点赞数',
  favorite_count INT DEFAULT 0 COMMENT '收藏数',
  download_count INT DEFAULT 0 COMMENT '下载次数',
  status INT DEFAULT 0 COMMENT '0=正常 1=已举报 2=已删除',
  create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
  INDEX idx_user_id (user_id),
  INDEX idx_course_name (course_name),
  INDEX idx_category (category),
  INDEX idx_create_time (create_time)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='学习资料';
```

### 2.2 study_share_likes（点赞表）

```sql
CREATE TABLE study_share_likes (
  id BIGINT AUTO_INCREMENT PRIMARY KEY,
  share_id BIGINT NOT NULL COMMENT '资料ID',
  user_id BIGINT NOT NULL COMMENT '点赞者ID',
  create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
  UNIQUE KEY uk_share_user (share_id, user_id),
  INDEX idx_user_id (user_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='学习资料点赞';
```

### 2.3 study_share_favorites（收藏表）

```sql
CREATE TABLE study_share_favorites (
  id BIGINT AUTO_INCREMENT PRIMARY KEY,
  share_id BIGINT NOT NULL COMMENT '资料ID',
  user_id BIGINT NOT NULL COMMENT '收藏者ID',
  create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
  UNIQUE KEY uk_share_user (share_id, user_id),
  INDEX idx_user_id (user_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='学习资料收藏';
```

### 3.3 Service：`StudyShareService.java`

| 方法 | 说明 |
|------|------|
| `getList(courseName, category, page, size)` | 查资料列表，按时间倒序，可按课程/分类筛选 |
| `getDetail(shareId, userId)` | 查资料详情，含是否已点赞/收藏 |
| `upload(userId, share)` | 上传资料（先调upload接口获取fileUrl再调此接口） |
| `delete(userId, shareId)` | 删除资料（仅上传者） |
| `like(userId, shareId)` | 点赞（已点赞则取消） |
| `favorite(userId, shareId)` | 收藏（已收藏则取消） |
| `download(shareId)` | 下载+1，download_count+1 |
| `report(userId, shareId)` | 举报资料，status=1 |
| `getMyShares(userId)` | 我上传的资料 |
| `getMyFavorites(userId)` | 我收藏的资料 |

### 3.4 Controller：`StudyShareController.java`

| 方法 | URL | 请求方式 | 参数 |
|------|-----|---------|------|
| 查列表 | `/api/study-share/list` | GET | `courseName`(可选), `category`(可选), `page`, `size` |
| 查详情 | `/api/study-share/detail` | GET | `id=1` |
| 上传资料 | `/api/study-share/publish` | POST | Body: JSON（含fileUrl） |
| 删除资料 | `/api/study-share/delete` | POST | `shareId=1` |
| 点赞/取消 | `/api/study-share/like` | POST | `shareId=1` |
| 收藏/取消 | `/api/study-share/favorite` | POST | `shareId=1` |
| 下载 | `/api/study-share/download` | POST | `shareId=1` |
| 举报 | `/api/study-share/report` | POST | `shareId=1` |
| 我上传的 | `/api/study-share/my-shares` | GET | 无 |
| 我收藏的 | `/api/study-share/my-favorites` | GET | 无 |
| 上传文件 | `/api/study-share/upload` | POST | multipart `file` |
| 上传封面 | `/api/study-share/upload-cover` | POST | multipart `file` |

## 五、关键业务逻辑

1. **文件上传流程**：前端先选文件 → 调 `/api/study-share/upload` 获取 fileUrl → 再调 `/api/study-share/publish` 提交资料信息
2. **封面图**：可选上传封面（类似活动封面），不上传则前端根据 fileType 显示默认图标（PDF/DOC/PPT等）
3. **文件大小显示**：前端转换 fileSize，<1MB 显示 KB，>=1MB 显示 MB（如 `2.3MB`）
4. **点赞切换**：同表白墙，查表判断是插入还是删除
5. **收藏切换**：同点赞逻辑
6. **下载计数**：调 download 接口时 download_count+1，前端获取文件URL后通过系统浏览器打开
7. **课程名关联**：courseName 是自由文本，不关联课程表，用户手动输入或从已有列表选

## 六、文件存储

- 上传目录：`uploads/`（与项目其他上传一致）
- 文件URL格式：`/uploads/xxx.pdf`
- 前端访问：`${ApiService.baseUrl}${item.fileUrl}`
- 文件类型白名单：`pdf, doc, docx, ppt, pptx, xls, xlsx, jpg, jpeg, png, zip, rar`
