# 功能三：表白墙/树洞（ConfessionWall）

> 匿名或实名发帖，倾诉心事、表白、吐槽

---

## 一、功能描述

1. 用户发布帖子（支持匿名/实名、支持配图、选择标签分类）
2. 浏览帖子列表，按分类筛选，支持下拉刷新
3. 查看帖子详情
4. 其他用户评论/回复
5. 点赞帖子
6. 举报不良帖子
7. 用户可删除自己的帖子

---

## 二、数据库建表

### 2.1 confession_posts（帖子表）

```sql
CREATE TABLE confession_posts (
  id BIGINT AUTO_INCREMENT PRIMARY KEY,
  user_id BIGINT NOT NULL COMMENT '发布者ID',
  content TEXT NOT NULL COMMENT '帖子内容',
  images VARCHAR(1000) DEFAULT '[]' COMMENT '图片路径JSON数组',
  category VARCHAR(20) DEFAULT '树洞' COMMENT '分类：表白/树洞/吐槽/交友',
  is_anonymous INT DEFAULT 0 COMMENT '0=实名 1=匿名',
  like_count INT DEFAULT 0 COMMENT '点赞数',
  comment_count INT DEFAULT 0 COMMENT '评论数',
  status INT DEFAULT 0 COMMENT '0=正常 1=已举报 2=已删除',
  create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
  INDEX idx_user_id (user_id),
  INDEX idx_category (category),
  INDEX idx_create_time (create_time)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='表白墙帖子';
```

### 2.2 confession_comments（评论表）

```sql
CREATE TABLE confession_comments (
  id BIGINT AUTO_INCREMENT PRIMARY KEY,
  post_id BIGINT NOT NULL COMMENT '帖子ID',
  user_id BIGINT NOT NULL COMMENT '评论者ID',
  content VARCHAR(500) NOT NULL COMMENT '评论内容',
  is_anonymous INT DEFAULT 0 COMMENT '0=实名 1=匿名',
  create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
  INDEX idx_post_id (post_id),
  INDEX idx_user_id (user_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='表白墙评论';
```

### 2.3 confession_likes（点赞表）

```sql
CREATE TABLE confession_likes (
  id BIGINT AUTO_INCREMENT PRIMARY KEY,
  post_id BIGINT NOT NULL COMMENT '帖子ID',
  user_id BIGINT NOT NULL COMMENT '点赞者ID',
  create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
  UNIQUE KEY uk_post_user (post_id, user_id),
  INDEX idx_user_id (user_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='表白墙点赞';
```

### 3.3 Service：`ConfessionWallService.java`

| 方法 | 说明 |
|------|------|
| `getList(category, page, size)` | 查帖子列表，按时间倒序，可按分类筛选 |
| `getDetail(postId, userId)` | 查帖子详情，含评论列表、是否已点赞 |
| `publish(userId, post)` | 发布帖子 |
| `delete(userId, postId)` | 删除帖子（仅作者） |
| `like(userId, postId)` | 点赞（已点赞则取消） |
| `comment(userId, postId, comment)` | 发表评论 |
| `report(userId, postId)` | 举报帖子，status=1 |
| `getMyPosts(userId)` | 我发布的帖子 |

### 3.4 Controller：`ConfessionWallController.java`

| 方法 | URL | 请求方式 | 参数 |
|------|-----|---------|------|
| 查列表 | `/api/confession-wall/list` | GET | `category`(可选), `page`(默认1), `size`(默认20) |
| 查详情 | `/api/confession-wall/detail` | GET | `id=1` |
| 发布帖子 | `/api/confession-wall/publish` | POST | Body: JSON |
| 删除帖子 | `/api/confession-wall/delete` | POST | `postId=1` |
| 点赞/取消 | `/api/confession-wall/like` | POST | `postId=1` |
| 发评论 | `/api/confession-wall/comment` | POST | `postId=1`, Body含content和isAnonymous |
| 举报 | `/api/confession-wall/report` | POST | `postId=1` |
| 我的帖子 | `/api/confession-wall/my-posts` | GET | 无 |
| 上传图片 | `/api/confession-wall/upload` | POST | multipart `file` |

## 五、关键业务逻辑

1. **匿名处理**：isAnonymous=1 时，VO 中 publisherName 返回"匿名用户"，publisherAvatar 返回空串
2. **点赞切换**：查 confession_likes 是否存在记录，存在则删除+likeCount-1，不存在则插入+likeCount+1
3. **图片上传**：支持最多5张图，前端上传后获取URL，发布时 images 字段传 JSON 数组字符串如 `["/uploads/a.jpg","/uploads/b.jpg"]`
4. **分类标签颜色建议**：表白=粉色、树洞=蓝色、吐槽=橙色、交友=紫色
