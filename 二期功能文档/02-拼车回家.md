# 功能二：拼车回家（Carpool）

> 校园拼车，结伴出行，发布/搜索拼车信息

---

## 一、功能描述

1. 用户发布拼车信息（出发地、目的地、出发时间、车座数、备注）
2. 其他用户浏览拼车列表，按目的地/状态筛选
3. 用户可以加入拼车（占一个座位）
4. 发起人可以取消拼车
5. 乘客可以退出拼车
6. 查看我发布的和我参与的拼车

---

## 二、数据库建表

### 2.1 carpool_orders（拼车单）

```sql
CREATE TABLE carpool_orders (
  id BIGINT AUTO_INCREMENT PRIMARY KEY,
  user_id BIGINT NOT NULL COMMENT '发起人ID',
  departure VARCHAR(100) NOT NULL COMMENT '出发地',
  destination VARCHAR(100) NOT NULL COMMENT '目的地',
  departure_time DATETIME NOT NULL COMMENT '出发时间',
  max_passengers INT DEFAULT 4 COMMENT '最大乘客数（不含司机）',
  current_passengers INT DEFAULT 0 COMMENT '当前乘客数',
  contact_phone VARCHAR(20) DEFAULT '' COMMENT '联系电话',
  remark VARCHAR(500) DEFAULT '' COMMENT '备注',
  status INT DEFAULT 0 COMMENT '0=招募中 1=已满 2=已出发 3=已取消',
  create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
  INDEX idx_user_id (user_id),
  INDEX idx_destination (destination),
  INDEX idx_status (status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='拼车单';
```

### 2.2 carpool_passengers（乘客表）

```sql
CREATE TABLE carpool_passengers (
  id BIGINT AUTO_INCREMENT PRIMARY KEY,
  order_id BIGINT NOT NULL COMMENT '拼车单ID',
  user_id BIGINT NOT NULL COMMENT '乘客ID',
  create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
  UNIQUE KEY uk_order_user (order_id, user_id),
  INDEX idx_user_id (user_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='拼车乘客';
```

### 3.3 Service：`CarpoolService.java`

| 方法 | 说明 |
|------|------|
| `getList(destination, status)` | 查拼车列表，可按目的地/状态筛选 |
| `getDetail(orderId, userId)` | 查拼车详情，含乘客列表 |
| `publish(userId, order)` | 发布拼车，发起人自动加入 |
| `join(userId, orderId)` | 加入拼车，current_passengers+1，满员改status=1 |
| `cancelJoin(userId, orderId)` | 退出拼车，current_passengers-1 |
| `cancelOrder(userId, orderId)` | 取消拼车（仅发起人），status=3 |
| `getMyOrders(userId)` | 我发布的+我参与的拼车 |

### 3.4 Controller：`CarpoolController.java`

| 方法 | URL | 请求方式 | 参数 |
|------|-----|---------|------|
| 查列表 | `/api/carpool/list` | GET | `destination`(可选), `status`(可选) |
| 查详情 | `/api/carpool/detail` | GET | `id=1` |
| 发布拼车 | `/api/carpool/publish` | POST | Body: JSON |
| 加入拼车 | `/api/carpool/join` | POST | `orderId=1` |
| 退出拼车 | `/api/carpool/cancel-join` | POST | `orderId=1` |
| 取消拼车 | `/api/carpool/cancel` | POST | `orderId=1` |

## 五、关键业务逻辑

1. **发布拼车**：发起人不算乘客，current_passengers 从 0 开始
2. **加入拼车**：检查是否满员（current_passengers >= max_passengers），通过后 current_passengers+1，满员改 status=1
3. **退出拼车**：删除记录，current_passengers-1，如果 status=1 且 current_passengers < max_passengers 则改回 status=0
4. **取消拼车**：仅发起人可操作，status 改 3
5. **出发时间格式**：前端用 DatePicker 选日期 + 时间输入，传给后端格式 `2026-07-30 18:00`
